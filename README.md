# Cpsmic Day

Aplicação web desenvolvida com React e Vite que utiliza a API APOD da NASA.

## Funcionalidades

- Pesquisa de publicações da NASA por dia e mês.
- Consulta de diferentes anos a partir do ano inicial escolhido.
- Galeria de imagens com título e data.
- Visualização ampliada com descrição da publicação.
- Validação de datas e tratamento de erros.

## Tecnologias

- React
- JavaScript
- HTML e CSS
- Vite
- API NASA APOD

## Como executar

É necessário ter Node.js instalado.

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no terminal.
3. Instale as dependências:

npm install

4. Execute:

npm run dev

5. Abra o endereço local informado pelo Vite.
